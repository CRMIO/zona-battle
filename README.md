# Zona Battle

Battle royale 2D con vista dall'alto, giocabile nel browser (computer e telefono).

**Gioca:** https://crmio.github.io/zona-battle/

- 100 giocatori (tu + 99 bot con intelligenza artificiale) su una mappa con villaggi, laghi e isole
- Lancio dal bus volante, caduta libera e deltaplano
- Casse, 5 armi in 5 rarità, cure, scudi e una tempesta con 9 zone
- Costruzioni (muro, barriera, bunker) e modifiche (finestra, porta), oppure Zero Costruzioni
- Partite classificate con rank da Rame a Campione
- Negozio con monete: skin, deltaplani e picconi in 5 rarità

## Comandi

| Azione | Computer | Telefono |
|---|---|---|
| Muoversi | WASD | joystick a sinistra |
| Mirare e sparare | mouse e click | pulsante col proiettile (trascinalo per mirare) |
| Lanciarsi dal bus / aprire il deltaplano | Spazio | SALTA / APRI DELTAPLANO |
| Ricaricare | R | pulsante ricarica |
| Piccone | F | pulsante piccone |
| Costruire | Q, oppure Z X C per muro, barriera, bunker | COSTRUISCI e PEZZO |
| Modificare | G | MODIFICA |
| Aprire casse e raccogliere | E | USA |
| Mappa / pausa | M / Esc | MAPPA / II |

## Provarlo in locale

```
python3 -m http.server
```

poi apri http://localhost:8000/
